바람 설치 안내

지원 환경: Apple Silicon 맥(M1 이후), macOS 26 이상

1. Baram.app을 옆의 Applications 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 바람을 실행합니다.
3. 메뉴 막대의 말풍선 아이콘을 누르면 번역 창이 열립니다.

업데이트할 때는 실행 중인 바람을 종료한 뒤 앱을 교체하세요.
ZIP을 내려받았다면 압축을 풀고 Baram.app을 응용 프로그램 폴더로 옮기면 됩니다.

처음 실행할 때
이 배포본에는 Developer ID 서명과 Apple 공증이 없습니다.
앱 실행을 한 번 시도한 뒤 macOS에서 차단하면 시스템 설정 > 개인정보 보호 및 보안 > 확인 없이 열기(Open Anyway)에서 이 앱의 실행을 허용할 수 있습니다.
Apple 안내: https://support.apple.com/ko-kr/102445

사용 방법
다른 앱에서 글을 복사하고 ⌘⇧I를 누르면 자동으로 붙여넣고 번역합니다.
왼쪽 원문 전체가 선택되므로 ⌘C로 서식 없이 복사할 수 있습니다.
번역 결과는 오른쪽 복사 버튼 또는 ⌘⇧C로 복사합니다.
설정에서 클립보드 번역 단축키를 원하는 조합으로 바꿀 수 있습니다.
처음 사용하는 언어는 macOS의 다운로드 안내를 완료해 주세요.
